DEMONSTRAÇÃO

Estes projetos vieram das nossas conversas e os estados são de exemplo. No PC do trabalho, dê dois cliques em iniciar-escritorio.bat (pasta escritorio) e o escritório passa a mostrar o que está rodando de verdade.

SEM CONEXÃO

O servidor do Escritório parou de responder. Veja se a janela do iniciar-escritorio.bat ainda está aberta. Os dados abaixo são da última leitura.

Como ligar no PC do trabalho

  1. Copie a pasta escritorio deste repositório para o PC (precisa do Node.js instalado).
  2. Dê dois cliques em iniciar-escritorio.bat. O navegador abre em http://localhost:7777.
  3. Os projetos em que você já usou o Claude Code ou o Codex aparecem sozinhos. Para testar se o app responde, coloque a url ou a porta de cada um no projetos.json.
