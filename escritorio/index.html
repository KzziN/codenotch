Como ler o escritório
Telão: o app do projeto rodando. Ao vivo quando o Escritório roda no seu PC.
Servidor: luz verde é app no ar, vermelha é app com erro.
Robô: agente de IA, com o nome no crachá da mesa.
Você: o projeto está aberto no seu editor.
Quadro da esquerda: uma janelinha para cada CMD aberto.
Balão: lupa lendo, lápis editando, >_ rodando comando, … pensando, ? esperando você, ! erro, ✓ terminou.

Abrir no celular, de qualquer lugar

Aponte a câmera do celular para o código ou use o link abaixo. Ele pede a senha do projetos.json. O link muda toda vez que o Escritório reinicia.

Como ligar no PC do trabalho

  1. Copie a pasta escritorio deste repositório para o PC (precisa do Node.js instalado).
  2. Dê dois cliques em iniciar-escritorio.bat. O navegador abre em http://localhost:7777.
  3. Os projetos em que você já usou o Claude Code ou o Codex aparecem sozinhos. Para o telão mostrar o app e testar se ele responde, coloque a url de cada um no projetos.json.
